## Decision to make

Which questions and deliverables should post-processing analysis support first?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** Researchers + analysis maintainers. No person is assigned. **Resolve:** Before analysis workspace.

## Context

Area: Science / results. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d15) for the shared snapshot.

## Options

1. Browse files only.
2. curated existing analyses with reviewable parameters.
3. a general analysis marketplace.

## Recommendation

Expose a small agreed set of existing analyses and their input requirements, units, exclusions, and provenance; export figures/tables with a run manifest. Keep processing and analysis selections separate.

## Trade-offs and questions to resolve

Decide population versus single-session scope, condition/time-window handling, figure formats, statistical review, and whether comparing two run outputs is required in the first milestone.
