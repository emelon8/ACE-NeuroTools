## Decision to make

How much freedom should users have when composing processing and analysis?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** Researchers + UX owner. No person is assigned. **Resolve:** Before workflow selection.

## Context

Area: Workflow. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d11) for the shared snapshot.

## Options

1. Curated templates with editable settings.
2. a module list with compatibility checks.
3. arbitrary node/graph editor.

## Recommendation

Start with named templates and a compatible module list. Suggestions explain their evidence and remain editable; record accepted suggestions in the configuration.

## Trade-offs and questions to resolve

Decide whether recommendations are deterministic rules or a later assisted service. A graph editor needs validation of ordering, branching, and intermediate data contracts.
