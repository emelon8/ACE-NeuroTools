## Decision to make

Which optional services should onboarding offer, and what may they read or transfer?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** Data steward + integration maintainer. No person is assigned. **Resolve:** Before integrations.

## Context

Area: Integrations. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d19) for the shared snapshot.

## Options

1. Local-only first.
2. opt-in existing Box connector.
3. additional storage/compute services.

## Recommendation

Keep local operation usable; make existing Box setup opt-in with a connection check and an explicit preview of selected transfers. Record source/version details without storing credentials in experiment history.

## Trade-offs and questions to resolve

Decide credential storage, offline behavior, failed transfers, provider version IDs, and whether usage/error telemetry exists. An integration suggestion is not consent to upload data.
