## Decision to make

Where does the GUI run, and which application operations do both interfaces call?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** UX owner + application maintainer. No person is assigned. **Resolve:** First.

## Context

Area: Experience / architecture. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d03) for the shared snapshot.

## Options

1. Native Python desktop.
2. browser UI with a local Python service.
3. hosted browser service.

## Recommendation

Evaluate native desktop and a local browser UI on file picking, long-running jobs, existing curation windows, accessibility, packaging, and maintenance. Keep shared Python application operations in either case.

## Trade-offs and questions to resolve

The Docker-app reference specifies usability, not a toolkit. A hosted service introduces separate data movement, identity, and operations decisions.
