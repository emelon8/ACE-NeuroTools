## Decision to make

Which file formats are supported first, and how should the user resolve ambiguous detection?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** Data owners + reader maintainers. No person is assigned. **Resolve:** Before import.

## Context

Area: Import. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d10) for the shared snapshot.

## Options

1. Only existing known formats.
2. a prioritized additional-format list.
3. general extension-driven probing.

## Recommendation

Begin with nominated existing UCLA/ONIX miniscope and Neuralynx/RHS2116 paths as applicable to real datasets; show evidence, missing companion files, and a manual override. Treat these as candidates until tested.

## Trade-offs and questions to resolve

Format detection, metadata inference, and experiment association are separate. Never treat a generic video extension or the first matching plugin as sufficient evidence for a scientific interpretation.
