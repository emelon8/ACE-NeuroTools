## Decision to make

What can a community extension contribute, and how is it enabled?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** Extension maintainer + community reviewers. No person is assigned. **Resolve:** Before extension API.

## Context

Area: Community / architecture. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d16) for the shared snapshot.

## Options

1. In-repository modules.
2. installed Python package extensions.
3. remotely discovered marketplace.

## Recommendation

Start with a documented versioned contract for one reader or analysis extension, explicit installation/enablement, compatibility checks, and a reference implementation. Keep core and extension behavior visible in the run record.

## Trade-offs and questions to resolve

Define inputs/outputs, parameter schemas, preflight hooks, errors/progress, and provenance. Python extensions execute code; do not claim a sandbox without implementing one. Decide review/trust policy before third-party distribution.
