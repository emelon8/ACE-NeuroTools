## Context

Area: Product / delivery. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d01) for the shared snapshot.

## Options

1. One complete miniscope path.
2. full paired multimodal path.
3. poster checkpoint with a separate implementation release.

## Recommendation

Start with one complete miniscope path and a representative real recording, then add paired modalities. Confirm October 7, 2026 explicitly before using it as a date commitment.

## Trade-offs and questions to resolve

A full multimodal milestone broadens dataset, synchronization, UI, and validation work before staffing is known.
