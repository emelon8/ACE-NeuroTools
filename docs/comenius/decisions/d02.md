## Decision to make

If one animal is recorded on three days and the team tries two parameter sets, how many experiments should appear?

**Status: open — a human decision is required.** The recommendation below is a planning proposal, not an accepted implementation choice.

**Suggested participants:** Researchers + application maintainer. No person is assigned. **Resolve:** First.

## Context

Area: Domain. This topic comes from the Comenius planning synthesis of the supplied meeting and project brief. See the [decision register](https://github.com/emelon8/experiment_analysis/blob/proj-comenius/docs/comenius/decisions.md#d02) for the shared snapshot.

## Options

1. One experiment per session.
2. one experiment per scientific protocol with multiple sessions.
3. user-defined collections with explicit session/subject identity.

## Recommendation

Use project → experiment → recording sessions, with subjects referenced independently and analysis runs recorded separately; first validate this model against two real lab examples.

## Trade-offs and questions to resolve

Do not migrate every CSV line into a subject or an experiment until this is resolved. A rerun should not ambiguously create a new scientific experiment.
