Project goal: human-in-the-loop and auditability; existing PR #68 provides the selector to integrate.

## What to build

Connect existing crop/component-review tools to the Comenius run/result workflow. Preserve the original estimates and make each researcher’s accepted curation traceable to a specific artifact.

## Acceptance criteria

- [ ] Coordinate explicitly with PR #68 before implementation; demonstrate reuse of the component selector rather than reimplementing it.
- [ ] Crop coordinates, component accept/reject choices, configured quality checkpoints, and applicable reasons are recorded against the originating run/artifact.
- [ ] Submitting curation produces a new version or derived artifact under the agreed policy and retains the source estimates.
- [ ] Cancel/reopen leaves a clear draft or unchanged state; downstream analysis consumes the explicitly selected reviewed artifact.
- [ ] Headless runs use a recorded prior selection or agreed policy and never silently claim that human review occurred.
