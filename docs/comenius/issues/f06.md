## What to build

After a run, browse outputs from its experiment, open an artifact, inspect what produced it, and export an explicitly selected result bundle for a collaborator.

## Acceptance criteria

- [ ] Experiment navigation shows separate runs, their state, timestamps, configuration revisions, and available results.
- [ ] An artifact links to input identity, effective configuration, pipeline/module/software versions, relevant environment, human choices, and logs under the agreed provenance contract.
- [ ] A second run preserves the first run’s outputs; failed and partial outputs are visibly distinguished.
- [ ] Export previews included metadata/results/recordings and omits credentials; a recipient can inspect the manifest and identify missing external data.
- [ ] A GUI export and CLI export obey the same selection rules; a reviewer traces one figure/table back to its generating run.
