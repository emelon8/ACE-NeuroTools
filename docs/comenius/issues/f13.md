## What to build

After reviewed processing/alignment, let a researcher select a small agreed set of existing analyses, review inputs/settings, execute them, and inspect/export linked results.

## Acceptance criteria

- [ ] Analysis selection explains required signals, time windows, conditions, units, and supported scope.
- [ ] Only explicitly selected analyses run; users can analyze compatible saved results without repeating raw-data processing.
- [ ] Each analysis records exact source artifacts, alignment/curation versions, parameters, module version, and exclusions.
- [ ] Figures/tables and skipped/failed outcomes appear in the common results view and export.
- [ ] GUI/CLI parity and a nominated reference calculation are demonstrated; scientific interpretation/thresholds are reviewed by a human.
