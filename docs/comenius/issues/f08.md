## Status and source

**Planning draft — human decisions required.** Suggested ownership role: Workflow + UX owner; no person is assigned. Proposed stage: Trust and usability.

Meeting: users choose themselves or receive dynamic suggestions; computation and analysis are distinct steps.

## What to build

Present compatible processing/analysis choices for confirmed recordings, explain why a template or module is suggested, and save the researcher’s chosen workflow.

## Acceptance criteria

- [ ] A user can choose a named workflow and relevant modules without needing a suggestion.
- [ ] Suggestions state input evidence and compatibility requirements and can be rejected or edited.
- [ ] Incompatible combinations explain their missing prerequisites rather than silently dropping steps.
- [ ] Accepted module versions/options become part of the effective configuration used by preflight and CLI execution.
- [ ] Selecting a suggestion does not itself launch processing, install an extension, or send data to an external service.
