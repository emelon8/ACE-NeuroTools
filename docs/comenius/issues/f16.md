## Status and source

**Planning draft — human decisions required.** Suggested ownership role: Integration owner; no person is assigned. Proposed stage: Community / optional.

Meeting: optional integrations in setup; current project includes Box support.

## What to build

Allow a researcher to configure one approved existing storage integration, test its connection, choose files, inspect the planned transfer, and attach fetched inputs to the common import workflow.

## Acceptance criteria

- [ ] Local workflows remain usable without an integration; available optional integrations and their requirements are understandable.
- [ ] Connection setup/test and selected transfers require explicit user actions under the agreed consent model.
- [ ] Credentials are excluded from experiment revisions, logs, and shared bundles.
- [ ] Offline, missing, changed, partial, and failed downloads have visible recovery paths; successful imports record source identity/version and checksums as agreed.
- [ ] GUI and CLI use the same adapter behavior; uploads or additional providers are included only if explicitly selected in D19.
