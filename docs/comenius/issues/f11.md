Project brief: multimodal analysis; existing ephys support should join the GUI workflow.

## What to build

Use the common import, settings, preflight, execution, and results flow for one nominated electrophysiology recording and channel.

## Acceptance criteria

- [ ] A supported real ephys dataset is detected with visible channel names, sampling information, and required metadata.
- [ ] The researcher selects channels and processing options with units and validation before approving a run.
- [ ] Existing ephys processing produces inspectable signals/results and provenance through the shared run lifecycle.
- [ ] Missing channels, invalid ranges, import failures, and cancellation produce understandable outcomes.
- [ ] The same saved configuration works from CLI; a nominated scientific reviewer checks the output against an agreed reference.
