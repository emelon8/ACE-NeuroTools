# Lab practice and feedback checklist

Use your own copy of the practice project and the short recording supplied by
the maintainer. Ask for suitable settings before starting; selecting a default
does not show that it is appropriate for your recording. If an instruction is
unclear, record where you got stuck and ask for help.

For each task, mark **Completed alone**, **Needed help**, or **Could not complete**.
Record the confusing instruction, what you expected, what happened, and any error.

1. **Open ACE.** Follow [installation and launch](gui_installation.md#for-lab-members).
   Check that ACE opens in your browser.
2. **Find the assigned experiment.** Follow [Open ACE and a project](gui.md#open-ace-and-a-project).
   Check the subject, date, and recording folder against the supplied information.
3. **Locate the recording.** Follow [Check recording locations](gui.md#check-recording-locations).
   Choose the supplied local folder. If it is on Box, download the supplied
   recording outside ACE first; this app does not download from Box.
4. **Save a note.** Follow [Edit and save](gui.md#edit-and-save-details-or-settings).
   Add “Tested by [your name]” in **Notes** under **Experiment details**. Save, reload the project,
   and check the note is still present.
5. **Choose an image area.** Follow [Preview and crop](gui.md#preview-and-crop-a-movie).
   Draw the lab's requested area, move or resize it, and save. Reload the preview
   and check that it shows your saved selection.
6. **Process the short movie.** Follow [Review and run](gui.md#review-and-run-an-analysis).
   Select **Crop and preprocess movie**, use the lab's settings, review the files
   and output location, and start. Check for a completed run in Results.
7. **Find its outputs.** Follow [Find and reopen results](gui.md#find-and-reopen-results).
   Open the output folder and find the processed movie. Record unclear filenames
   or inventory explanations.
8. **Repeat and return.** Repeat the same analysis and check that both runs remain
   available in separate folders. Close the browser tab, reopen it using the
   complete launch address from ACE's terminal, and reopen the project if needed.
   Check that you can still find both runs. After a server restart, use its new
   launch address.
9. **Extract neurons, if assigned.** Follow [Review and run](gui.md#review-and-run-an-analysis)
   with **Calcium imaging (preprocessing and CNMF-E)** and the lab's extraction
   settings. Ensure both neuron extraction and estimates saving are enabled.
   Check that the completed run offers **Review extracted neurons**.
10. **Review and export neurons, if assigned.** Follow
    [Review neurons](gui.md#review-neurons-and-save-accepted-cells) and the lab's
    keep/reject criteria. Make a few decisions, reopen the same estimates to check
    they persist, then finish. Save curated copies and detect events using the
    supplied settings. Check the curation folder for the new outputs.

Send feedback with the task number, computer/operating system, experiment ID,
and screenshots or exact errors where useful. Tell us whether you could find
your results again without help. A successful practice run checks the workflow;
the lab still needs to assess the scientific results.
