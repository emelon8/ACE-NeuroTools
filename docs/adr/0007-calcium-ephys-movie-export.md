# Keep and repair the calcium + ephys movie export

## Context

`src/aceneurotools/multimodal/calcium_ephys_visualizer.py` defines one function,
`create_ca_ephys_movie`, which animates calcium frames with an overlaid ephys trace
and optional mean fluorescence and an infusion marker. No module in the package
imports it.

Origin (`git log --follow`): added in `6e37318` (2025-06-17, the `src2` era),
then carried through the package restructures, the ACE-NeuroTools rename and the
CalciumImaging naming change (`24812c3`, #139). It is documented as an optional
export in `notebooks/multimodal_alignment_tutorial.ipynb` (cell text: "Optional
movie export: `create_ca_ephys_movie` ... (resource-heavy)"), generated by
`scripts/build_tutorial_notebooks.py:707`. The experiment CSV columns
`ca_ephys_baseline_video_num`, `ca_ephys_slow_wave_video_num` and
`ca_ephys_burst_suppression_video_num` look like its inputs: they are excluded
from CaImAn parameters (`calcium_imaging_processor.py:543-544`) and labeled in
`gui/fields.py:53-55`, but nothing passes them to this function.

Against the current APIs it imports and calls existing functions with matching
signatures (`find_ca_movie_filenums`, `PathFinder.find`, the preprocessor's
`compute_projections`, `get_crop_coordinates`, `crop_movie`,
`compute_df_over_f`, and the `get_coords_dict_from_analysis_params`
compatibility alias). It has four defects for non-interactive use:

1. `get_crop_coordinates` is called without `headless` (line 89), so cropping
   always opens the interactive crop window, even with saved coordinates.
2. `mark_start_systemic=True` is the default, and line 115 indexes `[0][0]` into
   the events whose label starts with "start", raising `IndexError` when a
   recording has none.
3. `save_movie=True` writes to `saved_movies/` without creating it (line 188).
4. It returns `None`, so callers cannot find the saved movie, and `play_movie`
   defaults to `True` with a blocking `plt.show()` (line 183).

`framesPerFile` is read from the recording metadata with a fallback of 1000. UCLA
recordings merge `metaData.json` into that metadata, so the fallback applies only
to formats without that key. The same fallback is in
`miniscope_ephys_alignment_utils.py:215`; neither is changed here.

## Decision options

- **Keep and repair (recommended).** It is documented in the tutorial, works with
  current APIs, and `MultimodalPipeline` already holds every input it needs after
  a run (`calcium_imaging_pipeline.calcium_imaging_data_manager`,
  `ephys_idx_all_TTL_events`, `ephys_pipeline.ephys_data_manager.get_channel(...)`;
  `pipelines/multimodal.py:56-61`, `:261-309`). Do not call it automatically from
  `MultimodalPipeline.run()`: encoding an MP4 is slow, needs ffmpeg, and most runs
  do not need it.
- **Remove.** Deletes about 190 unused lines, but breaks the documented tutorial
  export and drops the only consumer of the `ca_ephys_*_video_num` columns.

## Proposed change

Add `headless: bool = False`. When true, cropping uses saved or supplied
coordinates without the crop window, the movie is not played, and the figure is
closed. Treat a missing "start" event as a warning that skips the marker. Create
`saved_movies/` before saving and return the saved path, or `None` when not
saving.

## Compatibility

- Defaults keep current interactive behavior (`headless=False`, `play_movie=True`).
- The return value changes from `None` to `str | None`; callers that ignored it are
  unaffected.
- Recordings without a "start" event now produce a warning instead of an
  `IndexError`. No pixel or trace values change.

## Unblocks

An opt-in "Export calcium + ephys movie" action for completed multimodal runs in
the GUI. The GUI run worker would call `create_ca_ephys_movie(..., headless=True,
save_movie=True)` with the experiment's `ca_ephys_*_video_num` or a chosen time
range, and list the returned file in the output inventory.

+def inputs(tmp_path, labels):
+    frames = 20
+    dm = SimpleNamespace(
+        metadata={"calcium imaging directory": str(tmp_path), "framesPerFile": frames, "frameRate": 20.0},
+        analysis_params={},

+    channel = SimpleNamespace(
