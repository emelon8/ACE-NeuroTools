Set up a Box app for the first time
  1. Open the Box Developer Console. Create a Server app using Client Credentials Grant.
  2. Ask your Box administrator to authorize the app. For an existing Box user, enable App + Enterprise Access and Generate User Access Tokens, then authorize the updated app.
  3. Copy the Client ID and Client secret from the app's Configuration page. Enter the numeric Box user ID below. For a service account, use the enterprise ID and share your recording folder with that account.
