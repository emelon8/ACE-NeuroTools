# Stats subpackage (ACE-NeuroTools)

Statistical engines (coherence, scatter correlation) orchestrated by `pipelines/stats.py`, plus a modular, library-only analysis toolbox (surrogates, wavelets, oscillatory events, correlograms, peri-event averages).

**Full reference:** [Stats API](https://aceneurotools.readthedocs.io/en/latest/api/stats/) — source: [`docs/api/stats.md`](../../../docs/api/stats.md).
