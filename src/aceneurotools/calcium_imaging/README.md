# Calcium imaging analysis (ACE-NeuroTools)

Shared movie preprocessing, motion correction, CaImAn/CNMF-E source extraction,
and postprocessing use generic CalciumImaging names. Acquisition readers remain
in `aceneurotools.miniscope`.

See [the calcium imaging guide](../../../docs/guides/calcium_imaging.md), including
compatibility names and acquisition limitations. Processing defaults are unchanged.
