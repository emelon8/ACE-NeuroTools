# Config subpackage (ACE-NeuroTools)

Loading and validation of user-editable configuration: `lab_config.json` (LabConfig), `stats_config.json` (StatsConfig), and per-subject `analysis_parameters.csv` helpers.

**Full reference:** [Config API](https://aceneurotools.readthedocs.io/en/latest/api/config/) — source: [`docs/api/config.md`](../../../docs/api/config.md).
